## پروژه مسیریابی هوشمند شهری شیراز

### معرفی پروژه
هدف این پروژه طراحی یک محیط مبتنی بر شبکه راه‌های شهر شیراز برای توسعه سیستم مسیریابی هوشمند با استفاده از هوش مصنوعی است.

در این پروژه، داده‌های خیابان‌های شیراز از OpenStreetMap دریافت شده و پس از بررسی و تحلیل، به یک شبکه دوبعدی (2D Grid) تبدیل شده‌اند تا در مراحل بعدی برای مسیریابی و الگوریتم‌های جست‌وجو استفاده شوند.

### منبع داده و مجوز استفاده
- **منبع داده:** OpenStreetMap
- **ابزار دریافت داده:** OSMnx
- **نوع شبکه:** راه‌های قابل رانندگی (Drive Network)
- **مجوز استفاده:** Open Database License (ODbL)
- **ذکر منبع:** © OpenStreetMap contributors

### مشخصات پروژه
- **محدوده پروژه:** شهر شیراز، استان فارس، ایران
- **تعداد گره‌ها:** ۴۲٬۲۷۵
- **تعداد یال‌ها:** ۹۱٬۳۹۴
- **سیستم مختصات:** UTM Zone 39N (EPSG:32639)
- **اندازه هر سلول شبکه:** ۱۰ در ۱۰ متر
- **ابعاد شبکه دوبعدی:** ۳۰۲۵ × ۲۶۴۶

### نحوه نمایش شبکه دوبعدی
شبکه راه‌ها به یک ماتریس دوبعدی تبدیل شده است:
- عدد `1`: سلول‌های دارای خیابان و قابل عبور
- عدد `0`: سلول‌های بدون خیابان

آمار شبکه:
- تعداد سلول‌های قابل عبور: ۴۸۸٬۶۵۴
- تعداد سلول‌های غیرقابل عبور: ۷٬۵۱۵٬۴۹۶

### محتویات پروژه
فایل ZIP پروژه شامل موارد زیر است:
- گزارش طراحی (Design Report)
- گزارش تحلیل اکتشافی داده‌ها (EDA Report)
- داده اصلی شبکه راه‌های شیراز با فرمت GraphML
- نمودارها و خروجی‌های آماری EDA
- فایل شبکه دوبعدی با فرمت NPY
- تصویر نمایشی شبکه دوبعدی با فرمت PNG

### محدودیت‌های پروژه
شبکه دوبعدی فعلی بر اساس هندسه خیابان‌ها ساخته شده است و هنوز اطلاعاتی مانند ترافیک لحظه‌ای، تمام محدودیت‌های عبور و موانع فیزیکی را شامل نمی‌شود. برای استفاده در مسیریابی نهایی، اعتبارسنجی بیشتری لازم است.
